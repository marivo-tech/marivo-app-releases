# SeaWalker App — Android downloads

Official Android installer (APK) for the **SeaWalker** app, which controls SeaWalker chargers and GPS anchor trolling motors over Bluetooth.

➡️ **[Download the latest version](https://github.com/jiafic-zh/seawalker-app-releases/releases/latest)** — open *Assets* and download `seawalker-<version>.apk`.

- Requires Android 8.0 or newer.
- Already installed? The app checks for updates by itself and can update in place (Settings › App updates).
- Also available on Google Play and the App Store (coming soon).

This repository only hosts release files. Website: [www.seawalkerboat.com](https://www.seawalkerboat.com) · Support: support@seawalkerboat.com
